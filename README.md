# Калькулятор возраста

Небольшое веб-приложение для расчёта возраста по дате рождения и выбранной дате.

## Запуск

Установка не требуется. Откройте файл `index.html` в Google Chrome, Microsoft Edge или Mozilla Firefox.

## Как пользоваться

1. Укажите дату рождения.
2. При необходимости измените дату расчёта. По умолчанию используется текущая дата.
3. Нажмите «Рассчитать».
4. В блоке результата отобразятся полный возраст, возраст в годах/месяцах/днях, следующий день рождения и количество дней до него.
5. Для нового расчёта можно нажать «Сбросить».

## Структура
!!!! поменять
- `index.html` — разметка страницы;
- `styles.css` — оформление и адаптивность;
- `app.js` — проверка дат и расчёты;
- `TZ.md` — техническое задание.

Программа работает локально. Сервер, база данных и подключение к Интернету не требуются.

## Архитектура

Пользователь вводит даты в интерфейсе `index.html`. JavaScript из `app.js` проверяет значения, выполняет расчёты и выводит результат на страницу. Файл `styles.css` отвечает только за внешний вид интерфейса.
